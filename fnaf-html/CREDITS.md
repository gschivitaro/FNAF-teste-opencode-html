# Créditos das imagens — Five Nights no SENAI

Todas as imagens foram baixadas para a pasta `assets/` e são usadas localmente pelo jogo.
O jogo não faz requisições de imagem pela internet em tempo de execução.

## Animatrônicos (imagens geradas por IA)

Geradas especificamente para este projeto com o serviço gratuito Pollinations.ai, usando prompts originais de animatrônicos de terror. Não representam personagens de franquias existentes.

- `assets/characters/bunny.jpg` — coelho animatrônico
- `assets/characters/chicken.jpg` — galinha animatrônica
- `assets/characters/foxy.jpg` — raposa pirata animatrônica
- `assets/characters/bear.jpg` — urso animatrônico

Serviço: https://pollinations.ai
